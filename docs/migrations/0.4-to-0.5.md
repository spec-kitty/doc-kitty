# Upgrading from 0.4.0 to 0.5.0

For an adopter whose site uses `@spec-kitty/doc-toolkit` 0.4.0. Toolkit 0.5.0
is a minor release with one breaking change, the only one that can ask
something of you. The [changelog](../../CHANGELOG.md) has every change in full.

## 1. Give every page a `kind`

The frontmatter gate (`validate-frontmatter`) requires `kind` on every page
again, as the convention always said
([ADR-0065](../adr/0065-kind-required-again.md)). A page without it fails with
`` `kind`: required ``. The Astro build still renders such a page.

Run the gate to find the pages:

```sh
npx dockitty-validate-frontmatter docs
```

Add a `kind` to each page it names, such as `Reference`, `How-To`, `Hub` for a
section `README.md`, or `ADR`. The [convention](../context/convention.md#kind-values)
lists the values. `dockitty-new-doc` and `dockitty-scaffold` already write one.

## 2. Or relax `kind` for now

If you cannot add `kind` everywhere yet, keep the 0.4.0 behaviour in your
charter, `docs/_meta/charter.yaml`:

```yaml
required_fields:
  optional: [ kind ]
```

Remove the entry once every page has a `kind`.

## Other changes

The rest of 0.5.0 needs nothing from you:

- A written-out or numeric date with no zone, such as `updated: May 1, 2024`,
  is now read as UTC, the same as an ISO date with no zone. Before, it was read
  in the build machine's time zone. A page dated this way can move by up to a
  day in feeds and the agent API, to the date it names. The gate still
  recommends `YYYY-MM-DDTHH:MM:SSZ`.
