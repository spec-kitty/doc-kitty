# Rhetoric

This section is a real Markua-authored conversion of Aristotle's *Rhetoric*,
Book I — not a demo fixture. It shows how a full converted work reads as
native doc-kitty pages: a custom top-level section registered in
`sections.yaml` rather than baked into a template, Markua footnotes and
editor's-note callouts, a native glossary built from the source's own term
list, and constructed reader personas wired to the audience surface.

- [Book I: Purposes and Definitions of Rhetoric](/rhetoric/book-one/) — a
  representative slice of the converted text (chapters 1–3), showing what
  rhetoric is for, its three species, and the topics orators argue from.
