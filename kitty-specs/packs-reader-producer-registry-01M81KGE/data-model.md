# Data model

## PackModel (ADR-0079 D4)

As in the ADR, with these value rules:

- `dir`: the pack directory's base name. `path`: the directory relative to `repoRoot` (default `process.cwd()`), POSIX.
- `identity`: from `pack.yaml`. A missing or unreadable descriptor gives `packId: ''`, `name: dir`, `version: ''`, `dependsOn: []` and a problem.
- `document`: present when `README.md` exists. `frontmatter` is kept on the model as `document.frontmatter` (an addition the codec's JSON tree has); it is never copied into page frontmatter (D6).
- `manifest`: present when `pack-manifest.yaml` exists and parses. `verified` is true only when every constituent and preset exists, every recomputed hash matches, and no candidate is unlisted.
- `presets`: `{name, path}` from files classified `preset`, sorted by path.
- `policy`: present when `mutability_policy` names a readable file.
- `inventory`: `source: 'manifest'` only when `manifest.verified`; kinds sorted by kind token, ids sorted (code units).
- `problems`: sorted by `file`, then `code`. Severity is always `warning`.
- `contract`: `readWith` is the snapshot's commit; `provenAgainst` is the `charterLock` commit when it is readable.

### Problem codes

| Code | When |
|---|---|
| `retired` | a file the contract classifies as retired |
| `unmodelled` | a file no rule takes |
| `symlink` | a symlink inside the pack (not followed) |
| `descriptor-missing`, `descriptor-unreadable`, `descriptor-missing-key`, `descriptor-unknown-key`, `descriptor-schema-version` | the `pack.yaml` cases |
| `readme-unreadable`, `readme-ambiguous-heading` | an unreadable README; an H1 after the start |
| `policy-missing`, `policy-unreadable` | `mutability_policy` names a missing or unparsable file |
| `manifest-unreadable`, `manifest-missing-file`, `manifest-unlisted`, `manifest-hash-mismatch`, `manifest-unknown-kind`, `manifest-schema-version` | manifest drift |
| `contract-unknown-key`, `contract-unknown-content-form` | from the snapshot's `file-kinds.yaml` |
| `charter-lock-mismatch`, `charter-lock-unreadable` | D2 |

## ContractSnapshot

```
<dir>/file-kinds.yaml
<dir>/schemas/<name>.schema.json
<dir>/conformance/classifier-cases.yaml
<dir>/contract.lock.json  {source, contractPath, tag?, commit, files: {<relpath>: <sha256 hex>}}
```

Invariant: the files on disk (except the lock) equal the lock's keys, and each hash matches.

## Producer

`{id, role: 'ownership' | 'provenance', scope?, recognition?: 'stamp-and-scope' | 'scope', retiredBy?, regenerateHint?}`

## OwnershipScope

- `{type: 'section', section?, kinds?}`: a page under `<section>/` (any one top-level section when `section` is omitted). `kinds` restricts it to page kinds.
- `{type: 'directories', section, dirs, kinds?}`: a page under `<section>/<dir>/` for one of `dirs`.

A page is generated by a producer when its scope matches and either the recognition is `scope` or the page's `generated.by` is that producer's versioned stamp.
