# Missions

Each page in this folder describes one mission planned for the example site:
what it sets out to change and why. They are forward-looking write-ups, not a
record of the current state (see [Architecture](/architecture/) for that).

This index page also gives the folder its name in the sidebar. A nested folder
is labelled with the title of its index page, so without this page the group
would fall back to a readable form of the folder name and the build would
report the missing title.
