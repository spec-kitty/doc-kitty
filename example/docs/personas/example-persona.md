The marzipan mapmaker passport sentinel — a distinctive phrase reserved for this
fixture so a Pagefind assertion can bind to this page's own search fragment on the
branded build.

Marzipan charts the uncharted hollows of a documentation tree and hands every
reader a route through it. This body prose stays inside Starlight's searchable
content region, so the passport layout keeps the page indexable while the card
above renders the identity strip, the name heading, and the generic-field grid.
