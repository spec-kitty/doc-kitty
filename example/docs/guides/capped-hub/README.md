# Capped hub

This hub has five pages and a sidebar child cap of 3, set with
`sidebar_child_cap: 3` in this page's frontmatter. Because five is more than
three, the sidebar shows this hub's overview link and one "5 pages" entry
instead of the five pages.

Open any of the pages below. The "5 pages" entry is marked as the current page,
and the previous and next links walk the pages in the order this list shows.
