# The capped entry

The entry reads "5 pages" here. Its text comes from the `sidebar.cappedLabel`
site option, else the `dockitty.sidebar.cappedEntry` UI string for the page's
language, else "{count} pages". It links to the hub, and it is marked as the
current page on every page below the hub.
