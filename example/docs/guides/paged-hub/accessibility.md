# Accessibility

The pagination is a navigation landmark named "Pagination". Each page number
is a link with a label such as "Page 2". The current page is plain text marked
as the current page, so it is announced but never links to itself. Previous
and Next are links while there is somewhere to go, and plain text at either
end.

Every link is at least 24 by 24 pixels and shows the focus ring when it has
keyboard focus. The listing needs no script.
